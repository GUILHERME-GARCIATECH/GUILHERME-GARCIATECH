# Guilherme Garcia

**Infraestrutura • DevOps • Automação • Engenharia de Sistemas**

Profissional de tecnologia na [Assessoria Tech](https://github.com/DEV-ASSESSORIA-TECH), com atuação em infraestrutura de TI, arquitetura de sistemas, automação e integração de serviços.

Trabalho com administração de ambientes Linux e Windows, virtualização, containers, observabilidade, monitoramento e desenvolvimento de soluções para ambientes corporativos.

Tenho interesse especial em infraestrutura como código, CI/CD, cloud computing, self-hosting e engenharia de plataformas, buscando arquiteturas eficientes, seguras e sustentáveis operacionalmente.

Graduando em **Tecnologia em Análise e Desenvolvimento de Sistemas (TADS)** pelo Instituto Federal de Mato Grosso (IFMT).

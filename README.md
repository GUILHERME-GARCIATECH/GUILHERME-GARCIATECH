## 💼 Projetos principais

### 📊 ERP - Em produção

Sistema voltado para gestão empresarial, com foco em organização de processos internos, cadastros, controle administrativo, relatórios e estrutura modular para novas funcionalidades.

### 🏛️ Gestão de licitações com integração PNCP - Em produção

Projeto focado no acompanhamento e organização de licitações públicas, com integração ao **PNCP**, filtros de pesquisa, organização de oportunidades e apoio à tomada de decisão.

### 📘 Gerador de diários de obra

Ferramenta criada para automatizar a geração de diários de obra, padronizando registros, organizando informações e reduzindo trabalho manual.

### 🔐 Backup via SFTP

Automação para realização de backups por SFTP, com foco em segurança, organização e confiabilidade no envio de arquivos.

### 🌐 Gateway web com reverse proxy Nginx

Servidor web gateway utilizando **Nginx** como reverse proxy para múltiplas aplicações, com organização de domínios, subdomínios e serviços.

### 🔒 Automação DNS-01 com JavaScript

Script em **JavaScript** para automação do desafio **DNS-01**, auxiliando na emissão e renovação de certificados SSL/TLS.
